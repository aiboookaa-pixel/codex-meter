# 常见问题

## 未找到 Codex

先确认安装的是包含 Codex App Server 的官方客户端或 CLI，已登录并可使用。客户端更新后可执行文件位置可能改变：设置 → 选择客户端，选择 ChatGPT／Codex.app，然后重新连接。不是所有 ChatGPT 应用都提供该能力。

## 连接超时、离线、过夜后仍显示旧额度

检查官方客户端登录和网络，点击重新连接。应用会约每 60 秒兜底获取并在唤醒后尝试恢复。重置时间已过不等于成功获得新周期：等待成功同步，不把缓存当实时数据。勿为排查关闭全局安全机制或修改 DNS／代理。

## 手机一直显示旧数据

1. Mac 应用必须运行；确认额度更新时间在推进。
2. 设置中确认同步启用、目录是 Scriptable 根目录、最近导出没有报错。
3. iPhone 和 Mac 使用相同 iCloud 账号，Scriptable iCloud 权限已开启。
4. 手机文件尚未下载时等待 iCloud，再手动运行 CodexMeter。
5. 自动 Widget 刷新由 iOS 决定，省电模式等可能延迟，不能承诺每 15 分钟刷新。

手动运行的提示会区分未生成文件、iCloud 下载／读取失败、格式错误和不支持的版本。没有有效缓存时不显示假 0%。

## 为什么赠送重置没有“下一次恢复日期”

仅能展示 API 确实返回的发放和到期日期。到期不是下次发放，官方没有可靠返回的日期不能推测。

## 构建、通知、登录启动

构建需要完整 Xcode，并在 Xcode 首次启动时完成必要组件安装。通知需系统授权；登录启动使用 ServiceManagement，系统可能要求在登录项设置确认。测试配置使用 CODE_SIGNING_ALLOWED=NO，发行脚本另做本地临时签名。未公证与恶意代码不是同一个判断，但必须确认来源可信后再运行。

## 反馈时附什么

提供应用／脚本版本、macOS／iOS 版本、客户端版本、报错文字和重现步骤。截图先遮掉账号、真实额度及其他私人内容；不要上传客户端完整协议日志或真实 usage.json。
