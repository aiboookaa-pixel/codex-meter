# 隐私说明

本项目不设自建服务器、分析 SDK、广告 SDK、账号系统或后台上传服务。

Mac 本地保存最近额度窗口、重置时间、同步时间、可选赠送重置信息、通知去重和用户设置。用户选择的客户端／同步目录以 bookmark 恢复。手机仅保存有效额度快照，用于 iCloud 读取失败后的缓存。

官方客户端自身可能管理认证凭据，但 Codex Meter 不读取、导出或持久保存这些凭据。应用只使用已有 App Server 的额度读取能力，不代表官方客户端的隐私政策。

启用手机同步意味着最小额度快照交由用户自己的 iCloud Drive 同步；Apple iCloud 与 Scriptable 的隐私规则分别适用。不要把 usage.json 放到公共仓库、共享链接或公开网页。关闭同步后不会自动删除已生成文件；需要清除时由用户在 Scriptable 目录删除 CodexMeter 文件夹，并清理手机本地缓存。

开源仓库只包含源码、原创图标和合成测试样例，不包含维护者的登录、真实额度、运行缓存、系统 bookmark、签名证书、个人路径或本地提交历史。
